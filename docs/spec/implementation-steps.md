# 概要

Drupal 10でSO\-ARM\-100/101の知見共有ポータルを構築する。ユーザが実験データ・操作デモ・モデル・失敗事例を投稿し、検索・閲覧・ダウンロードできる。

# スコープ

- 投稿カテゴリを5種実装（家庭内作業／製造・組立／物流・搬送／研究・教育／データ収集・学習）。
- 一覧（Views／Drupal用語：ビュー）・詳細・検索・コメント（Comment／Drupal用語：コメント）・投票・ダッシュボード・プロフィールを提供。

# Content Type（Drupal用語：コンテンツタイプ／投稿の構造定義）仕様

- Content（Drupal用語：コンテンツエンティティ）「ロボット知見投稿」を作成。
- フィールド（Field／Drupal用語：フィールド）: タスク種別（5カテゴリのterm）、難易度、成功・失敗、機体モデル（100／101／両対応）、動画（MP4／S3）、軌道データ（HDF5／Parquet／LeRobot互換）、カメラ画像、YAMLメタデータ、使用グリッパ／センサ、環境条件、再現手順（Markdown）、技術的困難要素（定型＋自由記述）、タグ、所属機関・専門分野（プロフィール紐付け）。

# タクソノミー（Taxonomy／Drupal用語：タクソノミー）

- カテゴリ5種、難易度（初級・中級・上級）、機体モデル、技術タグ（ROS2／MoveIt／LeRobot／Jetson／模倣学習／強化学習／Diffusion Policy／ACT／VLA／ピック＆プレース／柔軟物把持／力制御／Isaac Sim など）。

# 技術方針

- JSON:API（Drupalモジュール）を有効化し、外部（ROS2等）とPOST／GET連携。
- データフォーマットはLeRobot互換（HDF5／Parquet＋YAML）。基本動作「掴む→移動→離す」を中心にスキーマ設計。
- リアルタイム連携拡張を考慮（WebSocket／SSEの拡張ポイントをコメントで明示）。
- 検索はSearch API（Drupalモジュール）またはElasticsearch統合。S3互換大容量ストレージ対応。
- 機体特性差（100:教育／軽量、101:高トルク／産業）をフィルタに反映。

# 実装ステップ

1. Docker Compose（Nginx＋PHP\-FPM＋DB＋Drupal）起動。
2. Drupal導入、JSON:API／Search API／Media／File（Drupalモジュール）有効化。
3. Content Type（Drupal用語：コンテンツタイプ）とフィールド（Field／Drupal用語：フィールド）定義。
4. タクソノミー（Taxonomy／Drupal用語：タクソノミー）作成（カテゴリ・難易度・機体・タグ）。
5. ストレージ設定（S3またはローカル）。
6. 検索実装（全文＋ファセット）。
7. Views（Drupal用語：ビュー）で一覧にフィルタ（カテゴリ／難易度／成功・失敗／機体）を実装。
8. 詳細テーマ（動画プレビュー、軌道DL、手順表示）。
9. コメント（Comment／Drupal用語：コメント）・投票（有用性／改善提案／追試）。
10. ダッシュボード（人気・最新・未解決課題）。
11. プロフィール拡張（履歴／専門／所属）。
12. JSON:API（Drupalモジュール）エンドポイント確認＆LeRobot対応。

# 完了条件

- 5カテゴリで一覧フィルタが動作。
- 動画・軌道・YAMLの登録／表示／ダウンロードが可能。
- タスク名・キーワード・タグの全文検索が機能。
- コメント（Comment）と投票が機能。
- JSON:APIで取得・登録が可能。
- Docker Compose一発起動。
- 将来拡張（ROS2 bag可視化・Isaac Sim再生）のコード内拡張ポイントがコメントで明示。
